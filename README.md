# LongFallBoots
Minecraft mod which adds Portal-inspired Long Fall Boots

**(Note: This requires Curios API)**

This mod adds Long Fall Boots inspired by Portal, which grant a configurable amount of fall resistance so you can survive falls from up to 10,000 blocks high, by default 4000.

The recipe for the boots is a bit complicated so I'd recommend using JEI or anything similar to view the recipes. It also changes with a few mods. 

The boots also have a custom model when worn. They can't be put in the regular boots slot, Curios API is used so it has a custom slot there.
